# Rühl zur Bühne

**Erst der Pump. Dann der Pokal.**

[Jetzt spielen](https://der-programmer1.github.io/ruehl-zur-buehne/) ·
[Quellcode auf GitHub](https://github.com/der-programmer1/ruehl-zur-buehne)

Ein inoffizielles Pixel-Fan-Spiel mit Markus Rühl: vom Keller-Gym durch die
Messehalle und Backstage bis zur Wettkampfbühne. Proteinshakes liefern Pump,
Kraftaktionen zerlegen Kisten und schieben Cardio-Bots aus dem Weg. Für die
Siegerpose auf der letzten Bühne brauchst du 100 Pump.

## Steuerung

- **Laufen:** A/D oder Pfeiltasten; auf dem Handy LINKS/RECHTS halten.
- **Springen:** Leertaste, W oder Pfeil hoch; auf dem Handy SPRUNG halten.
- **Kraftaktion / Siegerpose:** E oder PUMP. Kostet 25 Pump; ein Shake gibt 25.
- **Pause:** Esc oder die Pausentaste. Ton separat ein- und ausschalten.

An einem Spender stehen bleiben, um Pump nachzuladen. Checkpoints sichern deinen
Fortschritt innerhalb des Levels. Nach drei verlorenen Leben kannst du das
aktuelle Level erneut versuchen. Die drei Levels dauern beim ersten Spielen
ungefähr 5–10 Minuten, abhängig von Umwegen und Fehlversuchen.

Das statische Spiel wird im eigenen öffentlichen Repository entwickelt und über
GitHub Pages ausgeliefert. AppShelf verlinkt diese Version. Es gibt keine Anmeldung
und keine gemeinsame Rangliste. Bestwert und Toneinstellung werden lokal im
Browser gespeichert. Die Screenshots zeigen echte Desktop- und Touch-Ansichten.

Die Spiellogik und ein vollständiger Kampagnendurchlauf werden automatisch geprüft;
Browser-Tests decken Tastatur, Sprung, Pump, Pause, Ton und Mehrfinger-Steuerung ab.
