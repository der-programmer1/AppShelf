AppShelf ist eine statische Website und wird auf GitHub Pages ausgeliefert. Beim Laden verarbeitet GitHub technische Zugriffsdaten wie deine IP-Adresse. Details stehen in der Datenschutzerklärung von GitHub.

Die Angebotsseiten verwenden keine Analyse- oder Marketing-Werkzeuge. Das gewählte Farbschema wird lokal im Browser gespeichert. Die Anfragehilfe speichert deine Eingaben nicht.

Wenn du die Anfragehilfe nutzt, werden deine Angaben nur in der geöffneten Seite zu einem E-Mail-Text zusammengestellt. Sie werden von der Website weder gespeichert noch an einen Server gesendet. Erst wenn du die Nachricht selbst in deiner Mail-App versendest, wird sie über deinen Mail-Anbieter an mich übermittelt.

Für Website-Anfragen erreichst du mich unter ich.der.programmer@gmail.com. Die per E-Mail mitgeteilten Angaben verwende ich zur Bearbeitung deiner Anfrage und gegebenenfalls zur Abstimmung des Projekts.

Externe Projekt-, Download- und Kontaktlinks öffnen die jeweiligen Angebote. Dort gelten die Datenschutzbestimmungen des jeweiligen Anbieters.
