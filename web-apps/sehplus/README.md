# SehPlus 1.6.2 als Web-App

Diese vollständig lokale Web-App erweitert die bereits im SehPlus-1.6.2-Quellcodearchiv enthaltene PWA. Android-Dateien und das ursprüngliche Android-Quellcodearchiv bleiben unverändert.

Enthalten: Kamera nach Freigabe, Standbild, Bilder und Videos aus Dateien, Video-Zeitregler und Wiedergabe, Rot-Grün/Rot-Grün+/Blau-Gelb/Kontrast/Neutral mit Stärke, optionale Helligkeitsautomatik, Originalansicht, Testbild-/Whiteboard-Lesemodus, Zoom und Verschieben, Pipette mit drei Messflächen, dominante Farbgruppen und Messqualität, Lichtkalibrierung, Zwei-Farben-Vergleich, lokale Farbmemos mit Einzel-/Gesamtlöschung, Farbkarten teilen, gefilterte Bilder speichern, sechs reproduzierbare Offline-Testmotive und technischer Testbericht. Die Farbanalyse ist aus `ColorAnalyzer.java` der Android-App portiert. Messen verwendet die ursprünglichen Bildpixel, unabhängig vom Anzeigefilter.

Ordner `web/` auf einem statischen HTTPS-Server bereitstellen. Kein Backend, kein Schlüssel, keine externen Bibliotheken. Lokal: `python3 -m http.server`, danach `http://localhost:8000/web/`. AppShelf: „Web-App öffnen“. iPhone/iPad: Safari → Teilen → Zum Home-Bildschirm; Mac ab Safari 17: Ablage → Zum Dock hinzufügen. Nach dem vollständigen Laden ist die App offline verfügbar.

Kamera und Medien werden nur auf diesem Gerät verarbeitet. Bilder und Videos bleiben im Arbeitsspeicher, werden beim Mediumwechsel freigegeben und nie hochgeladen. Nur bewusst gemerkte Farbwerte und Einstellungen werden lokal gespeichert. Farbmemos können gelöscht werden. Teilen/Speichern ist immer eine bewusste Aktion. Kameraverweigerung blockiert weder Dateiauswahl noch Testlabor. Canvas und Pipette unterstützen Tastaturbedienung; Farbnamen, HEX/RGB, Messqualität und Textvergleich vermitteln Ergebnisse unabhängig von Farbe.

**Browsergrenzen:** Dateigröße bis 200 MB. Die Bildverarbeitung ist auf maximal 1600 Pixel an der längsten Seite begrenzt, um Safari-Speicher und Rechenzeit zu schonen. Video-Codecs hängen vom Browser ab (MP4/H.264 ist die empfohlene Wahl). ImageCapture für Gerätefotos und die Taschenlampensteuerung sind optional und auf Safari meist nicht verfügbar; dann wird die Vorschau zum Standbild. Kamera wird im Hintergrund beendet. Haptik und System-Teilen hängen vom Gerät ab; ersatzweise kann eine Textdatei gespeichert werden. Kein identisches Ergebnis für unterschiedliche Kameras, Weißabgleich oder Lichtverhältnisse versprechen.

SehPlus unterstützt Farbwahrnehmung und ersetzt keine medizinische Untersuchung. Testlabor-Motive sind synthetische Testflächen, keine medizinischen Farbsehtests. Farbnamen sind Näherungen; Messsicherheit ist keine klinische Diagnose. Unabhängiges persönliches Projekt, keine offizielle Store-App. Keine Werbung, Konten oder Tracking.

Quellen: `web-apps/sehplus/`, gemeinsam `web-apps/shared/storage.js`. `python3 scripts/package-web-apps.py` erstellt die Katalogdateien und das vollständige Web-Quellcode-ZIP. Prüfung: `npm run test:web`, `npm run build`, `npm run test:web:browser`. Das Android-Archiv enthält zusätzlich unverändert die ursprüngliche PWA; für die erweiterte Version das separate Web-Archiv nutzen.
